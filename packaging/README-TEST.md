# Пёрышко 0.1.0 — тестовая сборка для Arch Linux x86_64

Композитор и шесть приложений: Файлы, Терминал, Заметки, Просмотр,
Текстовый редактор, Калькулятор. Это сборка для знакомства с оболочкой.
Физические мониторы, Fn-клавиши, сон/пробуждение и все бюджеты в DRM
ещё требуют ручной приёмки.

## Попробовать в окне без установки

Распакуйте `feather-de-0.1.0-arch-linux-x86_64.tar.gz`, откройте терминал
в распакованном каталоге и выполните:

```bash
./run-demo.sh --check
./run-demo.sh
```

Нужна работающая графическая сессия Wayland или X11 и аппаратный OpenGL/EGL.
Начальная настройка доступна в меню с пером → «Мастер приветствия…».
Чтобы выйти, закройте окно демо средствами своего рабочего стола.
Некоторые сочетания с Super/Alt перехватывает основной рабочий стол.

Демо сохраняет свои настройки и данные в `~/.local/state/feather-de-demo/`
(при заданном XDG_STATE_HOME — внутри него). Можно выбрать другую папку:

```bash
FEATHER_DEMO_HOME=/tmp/my-feather-demo ./run-demo.sh
```

Обычные файлы пользователя доступны: это отдельная конфигурация, а не песочница.
Запускайте новые экземпляры внешних приложений: уже открытый Firefox/Telegram
может показать окно в основной сессии. В оконном режиме аппаратные возможности
(например, управление мониторами) ограничены. За сообщения отвечает отдельная D-Bus шина.

## Зависимости

Пакет `.pkg.tar.zst` устанавливает зависимости через pacman. Для архива
понадобятся те же пакеты:

```bash
sudo pacman -Syu --needed glibc gcc-libs libinput libxkbcommon seatd mesa pam systemd-libs wayland libglvnd fontconfig noto-fonts dbus
```

Эта бинарная сборка требует **glibc >= 2.44**. Проверка `./run-demo.sh --check`
покажет отсутствующие связанные библиотеки. Системные библиотеки и драйверы
в архив не включены. Для Ubuntu/Mint и других дистрибутивов нужна отдельная сборка.
Точные сведения о сборке находятся в `BUILD-INFO.txt`.

Дополнительные возможности требуют установленных и работающих служб:
NetworkManager — сеть, BlueZ — Bluetooth, PipeWire + pipewire-pulse + libpulse
(`pactl`) — управление звуком; `xwayland-satellite` — X11-приложения в полной
сессии; `poppler` (`pdftoppm`) — полный рендеринг PDF (есть ограниченный встроенный fallback); `xdg-desktop-portal` — порталы;
`ddcutil` — DDC/CI внешних мониторов. Звуки используют доступный `pw-play`,
`paplay` или `canberra-gtk-play`.

## Установка пакета Arch

В каталоге с `.pkg.tar.zst`:

```bash
sudo pacman -U ./feather-de-0.1.0-2-x86_64.pkg.tar.zst
```

После выхода из текущего рабочего стола выберите «Пёрышко (прямой вывод DRM/KMS)»
на экране входа. Альтернатива: войдите в свободную TTY (Ctrl+Alt+F3) и запустите
`feather-session` от обычного пользователя. Аварийный выход — Ctrl+Alt+Backspace;
переключение консолей — Ctrl+Alt+F1…F12. Не запускайте композитор через sudo.

Лог полной сессии: `~/.local/state/feather-de/drm.log`.
Существующий экран входа автоматически не меняется; конфигурация greetd
устанавливается как отдельный пример `feather-greeter.toml`.
Удаление пакета: `sudo pacman -R feather-de`.

Установить файлы из архива тоже можно: `./install.sh --user` (в `~/.local`,
без сессии DRM и PAM) либо `sudo ./install.sh`. Парные команды удаления:
`./uninstall.sh --user` и `sudo ./uninstall.sh`. Выберите один способ установки;
для Arch предпочтителен pacman, который отслеживает файлы и зависимости.

## Проверка целостности и обратная связь

В каталоге загрузки: `sha256sum -c ИМЯ_ФАЙЛА.sha256`.
В распакованном архиве: `sha256sum -c SHA256SUMS`.

Для отчёта приложите модель GPU, `uname -a`, тип сессии (окно/DRM), описание
действий и лог. Запись оконного запуска:

```bash
FEATHER_PROFILE=1 ./run-demo.sh 2>&1 | tee feather-demo.log
```

Текущая рабочая версия исходников указана в BUILD-INFO; изменения упаковки
могут быть ещё не закоммичены. Контрольные суммы определяют содержимое сборки.
