# Заметки — 2026-10-24

`feather-notes` (каталог `notes/`) — простые заметки в стиле macOS Notes, Wayland-клиент
по образцу «Файлов»: рисует себя tiny-skia, в простое ничего не делает.

- Плавающая боковая панель: светофор, счётчик, поиск, список (заголовок, дата —
  время/«Вчера»/число, начало текста), жёлтое выделение. Справа ✎ «Новая заметка» и
  корзина «Удалить»; дата изменения над текстом; первая строка — жирный заголовок.
- Редактор: курсор, выделение мышью/Shift, двойной клик — слово, перенос по словам,
  стрелки/Home/End (Ctrl — по словам/к началу и концу), Backspace/Delete (Ctrl — слово),
  Tab — 4 пробела, Ctrl+A/C/X/V (буфер обмена Wayland, text/plain), Ctrl+Z, Ctrl+Shift+Z/Ctrl+Y,
  Ctrl+N новая, Ctrl+F поиск, Ctrl+W закрыть. Ввод без открытой заметки создаёт новую.
- Хранение: `$XDG_DATA_HOME/feather-notes/<id>.txt`, по файлу на заметку, запись через
  временный файл и rename в отдельном потоке, через 0,6 с после паузы в наборе; при закрытии
  окна несохранённое пишется синхронно. Удалённая заметка уходит в Корзину (можно вернуть);
  пустая заметка при уходе с неё удаляется без следа. Список — по времени изменения.
- В Dock/Launchpad пункт «Заметки» (id `builtin.notes`, закрепления сохраняются) запускает
  `feather-notes`, если он лежит рядом с композитором, иначе прежнее встроенное окно.

Проверка: `cargo test --release -p feather-notes` (набор, вырезание/вставка, отмена/повтор,
многобайтовые символы, перенос и движение курсора по строкам, удаление пустой, Корзина,
хранилище). Снимок во вложенной сессии с временным `XDG_DATA_HOME`.
Ограничения: только светлая тема (как «Файлы»), без папок, форматирования, вложений,
IME-предредактирования и мигания курсора (мигание стоило бы таймера в простое).
