# Общие поля ввода — 2026-10-24

Один `feather_ui::input::TextInput` теперь обслуживает Launchpad, Spotlight, поля
даты/времени и поиска часового пояса, пароль Wi-Fi, поиск и переименование в «Файлах»,
поиск в «Заметках». Ctrl+A выделяет, следующий текст заменяет выделение; доступны
стрелки, Shift-выделение, Ctrl+стрелки, Home/End, Delete/Backspace и удаление слов.
Клик ставит курсор, Shift+клик расширяет выделение, длинный текст прокручивается
горизонтально. Поддерживаются Unicode и Ctrl+A в русской раскладке.

Поиск фильтруется только при изменении текста: перемещение курсора и выделение не
сбрасывают прокрутку результатов. Поле переименования имеет постоянную геометрию,
совпадающую с областью клика в обоих режимах «Файлов»; Enter применяет, Escape отменяет.

Пароль рисуется точками с собственным курсором/выделением. Позиции клика переводятся
из точек в UTF-8 границы исходной строки. Сохраняется ограничение 64 байта и прежняя
проверка WPA/SAE. Хранилище и временный буфер вставки — `Zeroizing<String>`, передача
пароля worker происходит перемещением; закрытие и отмена очищают поле. Debug содержимое
не печатает. Новых таймеров и перерисовки в простое нет; клавиатурные действия
по-прежнему выполняются после фильтра Smithay, без изменения фокуса внутри него.

Проверки включают замену и вставку Unicode в середину строки, Ctrl+A без стирания,
клики и Shift-выделение в обоих представлениях «Файлов», фактическое переименование
временного файла, отмену, поиск «Заметок» без изменения заметки и передачу пароля
без раскрытия в диагностике. Изображения полей: `/tmp/feather-inputs`,
`/tmp/feather-controls/fixture-password.png`. Системное время и реальные сети тестами
не меняются.

Release без предупреждений; 115 тестов. Вложенный сценарий настроек ×2 (2880×1800):
0 тиков/5 с, RssAnon максимум 54 608 КиБ, терминал 0 тиков/5 с. Отчёт:
`/tmp/feather-inputs-settings-check`. Прежние пики GL/CPU остаются отдельной приёмкой.
