# Поиск, буфер, Launchpad, выбор окон и трей — 2026-10-24

Проверки выполнялись в собственном вложенном Feather на Hyprland wayland-1,
экран 3840×2160, ×2, пользователь продолжал работать в DRM на tty3. Ни клавиши,
ни клики хоста не отправлялись. Геометрия собственного окна менялась по проверенному PID.
Свои группы процессов остановлены по PID, рабочая сессия не перезапускалась.

## Что исправлено

- Поиск Ctrl+Shift+F: поле в шапке, Unicode без учёта регистра, история и мягкие
  переносы, отдельная подсветка активного совпадения, счётчик, Enter/Shift+Enter/F3,
  кнопки, Esc. Поиск порциями по 4096 ячеек, без копии истории и массива всех результатов.
  После окончания таймер удаляется; закрытый поиск не сканирует экран.
- OSC 52 теперь публикует текст через wl_data_device. Чтение `?` не поддерживается;
  неверные/слишком длинные OSC не выполняются. Кодек ограничен 64 КиБ OSC, около
  48 КиБ декодированного текста. Исходная ошибка Codex CLI связана с обращением его
  native clipboard к X11; бинарник установленного CLI содержит OSC52 fallback.
  Именно предупреждение CLI в его реальном диалоге не воспроизведено, исчезновение
  предупреждения не заявляется. Проверены резервный протокол и собственное копирование.
- Launchpad закрывается и при клике, и при Enter, прежде чем запустить приложение.
  Для значка Dock используется существующая задержка анимации запуска.
- Dock «окно из списка» активирует конкретный id, а не группу приложения.
- Alt+Tab: hit testing совпадает с отрисовкой; наведение выбирает, клик активирует,
  клик снаружи отменяет; событие не передаётся лежащему под панелью клиенту.
- Системный трей: [TRAY.md](TRAY.md).

## Повторение

```sh
cargo build --release
dbus-run-session -- cargo test --workspace -- --include-ignored
python3 bench/session-check.py search --output /tmp/feather-search
python3 bench/session-check.py search --dark --scale 1.25 --output /tmp/feather-search-dark
python3 bench/session-check.py copy --no-screenshot --output /tmp/feather-copy
python3 bench/session-check.py launchpad --no-screenshot --output /tmp/feather-launchpad
python3 bench/dock-resize-check.py dock --output /tmp/feather-dock
```

`bench/session-check.py` создаёт приватную D-Bus шину для каждого прогона. Терминал
запускается с PTY fixture; тестовые события вызывают те же обработчики клавиш и мыши,
что обычный ввод. `copy`: приложение захватывает мышь, публикует OSC52 «OSC52 → Wayland»;
затем Shift+протяжка и Ctrl+Shift+C копируют «terminal-copy». Оба результата прочитаны
wl-paste на **собственном вложенном socket**, а не из буфера пользователя.
`search`: 220 строк/3 русскоязычных совпадения, следующий/предыдущий, отсутствие
результатов, Esc и повторное открытие. Снимки светлой ×2 и тёмной ×1,25 просмотрены.
Dock: три окна, выбор каждого id и keyboard focus, циклическое переключение, меню,
клик по значку другого приложения в Alt+Tab. Launchpad: press/release закрывает сетку,
новое окно терминала действительно mapped.

## Замеры и границы приёмки

Все 80 тестов workspace прошли, включая изолированные D-Bus тесты. Release собирается
без предупреждений. В проверенных сценариях после завершения действий 0 тиков CPU/5 с,
у терминала с открытым поиском также 0. Один прогон Launchpad со снимком дал 1 тик,
повторный без readback — 0. Частота часов оболочки не менялась.

Выборочные значения RssAnon композитора раз в секунду:

| Сценарий | CPU, тиков/5 с | Максимум выборок, КиБ |
|---|---:|---:|
| Поиск, светлый ×2 (последний повтор) | 0 | 40 244 |
| Поиск, тёмный ×1,25 | 0 | 35 556 |
| Буфер, без readback ×2 (последний повтор) | 0 | 38 732 |
| Dock/выбор окон/Alt+Tab ×2 | 0 | 44 244 |
| Launchpad, без readback ×2 | 0 | 38 056 |
| Qt-трей, финальный release без readback ×2 | 0 | 39 408 |

Это выборки, не гарантированный мгновенный максимум. Снимок через GPU readback может
давать ранее известный краткий пик памяти выше 60 МБ. Хост Hyprland был на неактивном VT:
GL/CPU-пики по-прежнему видны, результаты не подтверждают ≤1 мс/кадр, FPS или холодный
старт в настоящем DRM. Эти прежние пункты бюджета остаются открытыми.
