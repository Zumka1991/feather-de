# Корзина как в macOS — 2026-10-24

## Что есть

- **Dock**: Корзина всегда последняя, в своём разделе: программы | свёрнутые окна |
  Корзина (без свёрнутых окон — один разделитель). Значок нарисован кодом без плитки, но
  с той же визуальной массой, что плитки: перфорированное стеклянное ведро в перспективе,
  блик/тень цилиндра, тень под дном; у полной — бумага внутри горлышка (задняя половина
  обода за бумагой, передняя — перед ней). Превью рядом с плитками:
  `FEATHER_ICON_PREVIEW=<dir> cargo test --release --bin feather-de trash_icon_preview -- --ignored`;
  Dock со свёрнутым окном: `FEATHER_DEBUG_OPEN=dock-minimized`.
  Клик открывает `~/.local/share/Trash/files` в «Файлах». Меню: «Открыть»,
  «Очистить Корзину…» (если не пуста) → окно подтверждения в модальном слое композитора
  (тот же, что у пароля polkit): Enter — очистить, Esc — отменить.
- **Состояние** пусто/полно: inotify на `Trash/files`, проверка одного элемента в коротком
  потоке; папки создаются при старте; при пересоздании папки слежение подключается заново.
  В простое ничего не опрашивается.
- **Перетаскивание на значок Корзины**: значки рабочего стола и файлы из программ,
  отдающих `text/uri-list` (наши «Файлы»), отправляются в Корзину. Уже лежащее в
  Корзине не трогается.
- **«Файлы» в Корзине**: кнопка «Очистить» в строке пути, в меню объекта «Вернуть»
  и «Удалить навсегда…», в меню папки «Очистить Корзину…». Delete в Корзине спрашивает
  удаление навсегда. Подтверждение — лист поверх окна, Enter/Esc.
- **Возврат**: по `Path=` из `.trashinfo`; занятое имя получает « 2», « 3»…, ничего не
  перезаписывается; недостающие папки создаются. Удаление навсегда работает только
  внутри Корзины. Очистка удаляет и осиротевшие `.trashinfo` и `directorysizes`.

## Проверка

- `cargo test --release -p feather-ui trash` — перемещение/возврат/удаление/очистка во
  временном `XDG_DATA_HOME`; `-p feather-files trash` — подтверждения и меню Корзины.
- Вложенно, **только с временным XDG_DATA_HOME** (сценарий сам это проверяет):
  `XDG_DATA_HOME=$(mktemp -d /tmp/ftr.XXXX) FEATHER_DEBUG_TRASH=1 FEATHER_DEBUG_INPUT_ONLY=1
  target/release/feather-de --windowed` с файлом в `Trash/files` — полный значок,
  подтверждение, Enter очищает, значок пустой.
- **Не проверено автоматически:** перетаскивание на значок Корзины (код общий с
  перетаскиванием на рабочий стол) и работа в DRM-сессии пользователя.
- Ограничения: только домашняя Корзина (без `.Trash-$uid` на других дисках), нет
  подсветки значка при наведении во время перетаскивания, нет звука очистки.
