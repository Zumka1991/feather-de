# Терминал (feather-terminal)

Свой терминал Пёрышка в стиле macOS Tahoe, со своим ядром эмуляции (по выбору пользователя —
без alacritty_terminal/vte). Крейт `terminal/` workspace; Dock «Терминал» и «Открыть в
терминале» (стол, «Файлы») запускают его, если он лежит рядом с композитором, иначе Konsole.

## Устройство

- `vt/parser.rs` — машина состояний DEC/ANSI (схема Пола Уильямса), UTF-8 в ground/OSC,
  параметры CSI с подпараметрами через двоеточие; DCS/SOS/PM/APC пропускаются до ST.
- `vt/term.rs` — экран, история (10 000 строк, хранятся без хвостовых пробелов), ячейка
  16 байт (символ, 2 цвета, флаги), широкие символы — две ячейки, комбинируемые знаки —
  отдельно по строке. SGR 16/256/truecolor (`;` и `:`), курсор, CUP/HVP/VPA/CHA, ED/EL/ECH,
  ICH/DCH/IL/DL, SU/SD, REP, DECSTBM, DECOM, DECAWM, IRM, LNM, табуляции, DEC special
  graphics, DECSC/DECRC, alt-экран 47/1047/1049, мышь 1000/1002/1003 + SGR 1006, 1004, 1007,
  bracketed paste 2004, synchronized output 2026, DECSCUSR, DA1/DA2, DSR 5/6, OSC 0/2/7/10/11/52,
  DECSTR, RIS, DECALN. Изменение размера без переразбивки (как xterm; история подтягивается).
- `pty.rs` — forkpty, окружение собирается до fork (в потомке только async-signal-safe),
  `TERM=xterm-256color`, `COLORTERM=truecolor`; неблокирующий master в calloop.
- `view.rs` — палитры светлая/тёмная (по appearance Пёрышка), «жирный = яркий», рамки
  U+2500–U+257F и блоки рисуются процедурно по сетке ячеек, курсор блок/черта/подчёркивание,
  полый без фокуса. Перерисовываются только изменённые строки в постоянный холст.
- `main.rs` — Wayland (sctk): CSD-окно со «светофором» и заголовком «имя — cols×rows»,
  вкладки, wp_fractional_scale + viewporter, Abgr8888. Шрифт — `FontSystem::new_monospace`
  общего крейта (SF Mono/JetBrains Mono/…/DejaVu Sans Mono) с цепочкой запасных (символы, CJK).
- `search.rs` — буквальный Unicode-поиск без учёта регистра по экрану/истории и мягким
  переносам; KMP порциями по 4096 ячеек, без копии истории и хранения всех совпадений.

## Клавиши

Ctrl+Shift+C/V — копировать/вставить (средняя кнопка — вставить), Ctrl+Shift+T/W — вкладка,
Ctrl+PgUp/PgDn — переключение, Ctrl+Shift+N — новое окно, Ctrl+Shift+K — очистить историю,
Shift+PgUp/PgDn/Home/End — история, Ctrl+= / Ctrl+− / Ctrl+0 и Ctrl+колесо — масштаб
(запоминается в ~/.config/feather-de/terminal.conf). Выделение мышью: протяжка, двойной клик —
слово, тройной — строка, Shift+клик — расширить. Ctrl+буквы работают и в русской раскладке.
Перетащенные файлы вставляются как пути в кавычках; вставка файлов из буфера — тоже.

Ctrl+Shift+F (или F3) — поиск, Enter/F3 — следующее совпадение, Shift+Enter/Shift+F3 —
предыдущее, Esc — закрыть. В поле работают Ctrl+A/C/V, Home/End, редактирование UTF-8;
есть кнопки перехода и счётчик. Выбранное совпадение оранжевое, остальные жёлтые.
Пустой запрос и закрытое поле не сканируют историю. Поиск alt-экрана не включает историю shell.

Если TUI (Codex, vim, htop) захватывает мышь, **Shift+протяжка**, затем Ctrl+Shift+C —
выделение и копирование самого терминала. Обычная мышь остаётся у программы.
OSC52 write-only передаёт UTF-8 в нативный Wayland clipboard, без обращения к X11;
`?` не читает буфер. Неверные/слишком длинные OSC игнорируются (64 КиБ OSC, ~48 КиБ текста).
Проверка поиска и обеих веток копирования: [SESSION_CHECKS.md](SESSION_CHECKS.md).

## Замеры (2026-10-23, вложенное Пёрышко ×2)

Исправлено Codex: исчезновение окна при ресайзе было паникой передачи кадра в SHM,
а не ошибкой VT/анимации. SCTK округляет slot до 64 байт; копируется только фактическая
область пикселей. Проверен аварийный размер 733×219 при ×2 и 16 последовательных
перетаскиваний краёв/углов с сохранением id окна и живого PID. Отчёт: [DOCK_RESIZE_CHECKS.md](DOCK_RESIZE_CHECKS.md).

Первый кадр 39–44 мс после запуска процесса (shell стартует параллельно). Простой: 0 тиков,
0 пробуждений за 5 с (сначала было ~120 пробуждений/с — configure без изменений запускал кадр;
исправлено). RssAnon 4,9 МБ после старта, 18 МБ после `seq 1 2000000` (история 10 000 строк +
фрагментация кучи — оптимизировать). `seq 1 2000000` выводится за 1,0 с.
Проверены вживую: цвета/атрибуты/рамки/CJK/комбинируемые, `ls --color`, htop, vim.
