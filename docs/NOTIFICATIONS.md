# Уведомления

## Устройство

- `src/notifications.rs` — worker `feather-notify` с собственным zbus-соединением.
  Метод `Notify` разбирает аргументы прямо на worker: обрезает строки, сводит
  body-markup к тексту, проверяет и уменьшает `image-data` (≤ 1024 px на входе,
  ≤ 96 px в памяти). В цикл событий уходит готовый `Incoming` через ограниченный
  канал (32). При переполнении баннер отбрасывается, D-Bus не блокируется.
- Имя `org.freedesktop.Notifications` запрашивается с `DoNotQueue`. Если имя уже занято
  (mako, dunst, демон хоста), сервер молча завершается и чужой демон работает дальше.
  Вложенный `--windowed` сервер не запускает: он делит шину с хостом.
  `FEATHER_DEBUG_NOTIFY=1` включает сервер принудительно, только внутри `dbus-run-session`.
- `shell.rs` — стопка баннеров (`toasts`, до 3, новые сверху). Закрытия и действия
  копятся в `notification_events`, композитор передаёт их worker в
  `flush_notification_events`: после кликов, тика и входящих событий.
  Перед `ActionInvoked` отправляется `ActivationToken`.

## Поведение

| Случай | Что происходит |
|---|---|
| `expire_timeout = -1` | 5 с |
| `expire_timeout = 0`, urgency critical | висит до закрытия |
| положительный timeout | столько мс, минимум 1 с |
| `replaces_id` | баннер обновляется на месте, id прежний |
| четвёртый баннер | самый старый уходит в центр |
| баннер истёк | уходит в центр без сигнала (возможность `persistence`); `transient` закрывается с причиной 1 |
| в центре больше 50 | самое старое закрывается с причиной 1 |
| клик по баннеру | действие `default`, если есть; затем закрытие с причиной 2 |
| кнопка действия | `ActionInvoked`; закрытие, если нет подсказки `resident` |
| крестик (при наведении) | закрытие с причиной 2 |
| `CloseNotification` | закрытие с причиной 3 |
| «Не беспокоить» или открытый центр | баннер только у critical, остальные сразу в центр |
| клик по карточке центра | действие `default`, если есть; удаление с причиной 2; центр закрывается |
| крестик карточки / группы, «Очистить все» | удаление с причиной 2 |

Наведение задерживает истечение, после ухода указателя отсчёт начинается заново. Срок
проверяет уже существующий секундный таймер, новых таймеров нет.

Иконка ищется по `image-data`/`image-path`, затем по `app_icon` (имя темы или путь),
затем через `desktop-entry`/имя программы в реестре .desktop. Если ничего не нашлось,
рисуется логотип Пёрышка.

## Центр уведомлений

Клик по часам открывает центр, как в macOS (дата и время остались в Системных настройках).
Внутри история, новые сверху и сгруппированы по программам. У каждой группы свой
крестик, у панели есть «Очистить все». Колесо прокручивает по одной строке: строки
не обрезаются, поэтому клипа нет. Escape или клик мимо закрывают панель. Открытие центра
переносит в него баннеры с экрана. Время «N мин назад» обновляется секундным таймером
только при смене минуты.

Над историей — календарь на месяц, отдельной стеклянной карточкой (как виджет macOS):
шесть недель с понедельника, сегодняшний день в синем кружке, выходные бледнее, дни
соседних месяцев серые. ‹ › листают месяцы, клик по «Октябрь 2026» возвращает к текущему;
при каждом открытии центра календарь снова на текущем месяце. Высота карточки постоянна.

«Не беспокоить» переключается в Control Center и сохраняется (`do_not_disturb` в
settings.conf). Пока он включён, у часов в меню-баре видна луна.

## Настройки по программам

Системные настройки → «Уведомления»: переключатель «Не беспокоить» и список программ,
приславших хотя бы одно уведомление. Клик по строке перебирает режимы: «Баннеры и
центр уведомлений» → «Только центр уведомлений» → «Выключены». Ключ программы — подсказка
`desktop-entry`, иначе `app_name`. Подпись берётся из реестра .desktop, если программа
там есть. Список ограничен 64 программами и хранится строками
`notify_app=ключ|подпись|banners|center|off` в settings.conf: управляющие символы и `|`
вырезаются, повреждённые строки отбрасываются. Выключенное уведомление отбрасывается
сразу, клиент получает закрытие с причиной 2. Срочные (critical) показывают баннер даже
в режиме «Только центр».

## Расписание «Не беспокоить»

На странице «Уведомления»: «По расписанию» включает ежедневный интервал, клик по строке
«Время» перебирает варианты 22:00–7:00, 23:00–8:00, 21:00–7:00, 0:00–9:00, 13:00–14:00.
Интервал может переходить через полночь и хранится как `dnd_schedule=from-to` в минутах.
Неверные значения и пустой интервал отбрасываются. Проверяет его уже существующий
секундный таймер: сравнение двух чисел, без новых таймеров. Действующее состояние —
ручной режим или интервал. Выключение вручную внутри интервала держится до его конца,
следующий интервал снова включает режим. Ручное включение интервал не снимает.
Луна в меню-баре, Control Center и страница настроек показывают действующее состояние.

## Звук

Новый баннер подаёт короткий сигнал. Обновление (`replaces_id`), «Не беспокоить»,
«Только центр» и открытый центр звука не дают, как и выключенный переключатель
«Звук уведомлений» (`notify_sounds` в settings.conf). Файл ищется на worker: абсолютный
`sound-file` с расширением oga/ogg/wav/flac, иначе `sound-name` (только `[A-Za-z0-9_-]`)
или «message-new-instant» из темы freedesktop в каталогах XDG. Если темы нет, доступен собственный короткий сигнал Пёрышка. Все звуки теперь
играет общий `feather-sound`: `pw-play`, `paplay` или `canberra-gtk-play` на worker,
одновременно только один процесс, без очереди сигналов. Зависший проигрыватель
завершается через 4 с. Системные сигналы и настройки — [SYSTEM_SOUNDS.md](SYSTEM_SOUNDS.md).

  центре 0/с.
