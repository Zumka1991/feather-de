# Приложения по умолчанию, дата и время — 2026-10-24

В системных настройках теперь шесть страниц. Новые — «Приложения» и «Дата и время».
Клик по часам верхней панели открывает дату и время. Рабочая DRM-сессия не перезапускалась.

## Приложения

Worker находит установленные браузеры/терминалы по Categories и MimeType desktop entries
в XDG_DATA_HOME и XDG_DATA_DIRS. «Терминал Feather» есть отдельным вариантом, независимо
от совместимого id старого значка Dock. Список выбора показывает реальное имя приложения.

Браузер: атомарно обновляются `mimeapps.list` — Default Applications и Added Associations
для http, https, HTML и XHTML. Сохраняются другие секции/типы, комментарии и предыдущие
приложения как fallback. Если уже есть `featherde-mimeapps.list`, он обновляется тоже.
При открытии настроек текущий выбор перечитывается через xdg-mime. Основа —
[спецификация MIME Applications](https://specifications.freedesktop.org/mime-apps/latest/default.html).

Терминал: `default_terminal` в settings.conf определяет Super+T/Super+Enter и меню
рабочего стола. «Файлы» вызывают соседний `feather-de --open-terminal <каталог>`:
короткоживущий launcher читает настройку и открывает выбранный терминал в каталоге.
Диск не читается в обработчике композитора. Если выбранный терминал удалён, используется
Feather/Konsole fallback. Сами закреплённые приложения Dock сохраняют своё назначение.

Также записывается `featherde-xdg-terminals.list`; для встроенного терминала создаётся
пользовательский desktop entry с X-TerminalArgExec. Это совместимость с **предлагаемой**
[спецификацией xdg-terminal-exec](https://github.com/Vladimir-csp/xdg-terminal-exec),
не универсальный системный стандарт; сам xdg-terminal-exec в проект не устанавливается.

## Дата и время

Страница читает настоящие Timezone, NTP, CanNTP и NTPSynchronized. Есть автосинхронизация,
поиск часового пояса (включая русские названия основных городов) и ручной ввод
`ГГГГ-ММ-ДД ЧЧ:ММ`. Ctrl+A очищает поле, Enter применяет, Esc завершает ввод/поиск.
Ручная установка доступна при выключенной автосинхронизации. Невозможная дата,
неоднозначное время при DST и годы вне 1970–2100 отклоняются с сообщением.

Вызовы [systemd-timedated](https://www.freedesktop.org/software/systemd/man/latest/org.freedesktop.timedate1.html):
SetTimezone(zone, true), SetNTP(value, true), SetTime(usec_utc, false, true).
Подтверждение администратора выполняет системный polkit-агент, запускаемый существующим
механизмом session services. Ошибки доступа показываются в окне. Если timedated
недоступен, изменения отключены. RTC/local-RTC настройки здесь не меняются.

Снимок обновляется при открытии страницы, кнопкой «Обновить» и после команды;
периодического D-Bus опроса нет. Сами часы на странице обновляются вместе с минутой
верхней панели. Доступность timedated после его отсутствия при запуске требует
перезапуска Feather; hotplug системной шины пока не реализован.

`src/system_preferences.rs` — отдельный worker, bounded очереди 8/2, IO/D-Bus/ожидания
вне event loop. Применение подтверждается состоянием службы, а не оптимистичной галочкой.
Фокус меняется обычным refresh_focus; ввод в поля не меняет фокус внутри фильтра клавиш.

## Проверка

```sh
cargo build --release
dbus-run-session -- cargo test --workspace -- --include-ignored
python3 bench/session-check.py defaults --no-screenshot --output /tmp/feather-defaults-budget
python3 bench/session-check.py defaults --page date --output /tmp/feather-date-visual
```

94 теста workspace прошли. Проверены сохранение MIME/терминала в приватных каталогах,
валидация ввода и вызовы timedated на отдельной D-Bus шине: точные типы аргументов,
защита ручного времени при NTP, актуальные свойства после вызова, отказ в авторизации.
Физические часы, часовой пояс и NTP хоста в тестах не менялись.

Вложенный сценарий создаёт свои desktop entries и конфигурацию, выбирает браузер и
терминал реальными кнопками, нажимает Super+T внутри собственного композитора, затем
вызывает тот же launcher, что «Файлы». Проверяются два mapped окна, живые PID,
каталог второго терминала и сохранённые ассоциации. Полная проверка реального
polkit-диалога и изменения часов в рабочей DRM-сессии остаётся пользовательской.
