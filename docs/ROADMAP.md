# Roadmap Пёрышка

Единый чек-лист. После каждой задачи отмечайте пункт (`[x]`) и, если нужно, дописывайте
ссылку на отчёт. Пункт считается выполненным только после проверки и без нарушения
бюджетов из [SPEC.md](SPEC.md) §2; «проверено пользователем в DRM» отмечайте отдельно.
Подробности уже сделанного — [CHANGELOG.md](../CHANGELOG.md).

## Безопасность и питание

- [ ] Экран блокировки (ext-session-lock, пароль через PAM), Super+L, блокировка при пробуждении
- [ ] Гашение экрана и сон по простою (idle-notify, idle-inhibit), logind
- [ ] Системные настройки → «Экран блокировки и энергосбережение»

## Уведомления

- [ ] Сервер `org.freedesktop.Notifications`, баннеры в стиле macOS, действия
- [ ] Центр уведомлений (история), настоящий «Не беспокоить», настройки уведомлений по программам

## Совместимость

- [ ] XWayland (запуск X11-программ)
- [ ] Глобальное меню GTK (`org.gtk.Menus` / `org.gtk.Actions`)

## Окна и рабочие столы

- [ ] Рабочие столы (Spaces) и Mission Control, жесты трекпада
- [ ] Переключение окон одного приложения (Alt+`)
- [ ] Горячие углы

## Мониторы

- [ ] Несколько мониторов, горячее подключение, расположение и основной монитор
- [ ] VRR, explicit sync, direct scanout
- [ ] Ночной режим (тёплые цвета по расписанию, гамма DRM)
- [ ] Яркость (logind / backlight), где есть железо

## Системные настройки — новые страницы

- [ ] Звук: микрофон (устройство, уровень), звуки предупреждений и интерфейса
- [ ] Сеть: сохранённые Wi-Fi, Ethernet, VPN (NetworkManager)
- [ ] Bluetooth (BlueZ): включение, поиск, подключение
- [ ] Клавиатура: автоповтор (задержка, скорость), Caps Lock, свои сочетания клавиш
- [ ] Dock: размер, положение (снизу/слева/справа), автоскрытие
- [ ] Оформление: цвет акцента и выделения, размер текста интерфейса
- [ ] Автозапуск программ при входе
- [ ] Об этом компьютере: процессор, память, видеокарта, диски
- [ ] Универсальный доступ: крупный текст, контраст, меньше прозрачности, залипание клавиш
- [ ] Язык и регион; перевод интерфейса на популярные языки
- [ ] Снимки экрана: папка и формат
- [ ] Конфиденциальность: доступ программ к записи экрана (портал)

- [ ] Системные звуки

## Производительность (приёмка бюджетов)

- [ ] Сцена + GL ≤ 1 мс на кадр на активном хосте (есть пики > 1 мс)
- [ ] Первые CPU-кадры панелей ≤ 4 мс (Spotlight, восстановление окна)
- [ ] Полный кадр окна настроек на worker (сейчас 5–48 мс с рамкой и тенью)
- [ ] Редкий пик памяти 61 МиБ при смене обоев (бюджет 60 МБ)
- [ ] Приёмка всех бюджетов в настоящей DRM-сессии
