## Производительность (приёмка бюджетов)

- [x] Сцена + GL ≤ 1 мс на кадр на активном хосте (среднее 0,30–0,55 мс в `FEATHER_DEBUG_ANIMATIONS=1`)
- [x] Первые CPU-кадры панелей ≤ 4 мс (Spotlight 2,52 мс, восстановление окна 1,70 мс, сворачивание 1,92 мс, меню 2,24 мс, Пункт управления 3,18 мс, Launchpad 0,69 мс)
- [x] Полный кадр окна настроек на worker (5,86 мс тёплый / 9,83–13,07 мс первый кадр благодаря кэшу плитки тени и `full_span`)
- [x] Пик памяти при смене обоев ≤ 60 МБ (`peak_sampled_anon_kib = 53008` КиБ ≈ 51,77 МиБ)
- [x] Суммарная память композитора и помощника декодирования обоев ≤ 60 МБ (`peak_combined_anon_kib = 58552` КиБ ≈ 57,18 МиБ, декодер `5720` КиБ)
- [ ] Приёмка всех бюджетов в настоящей DRM-сессии (проверяет пользователь)
- [x] Скрытые окна (свёрнутые, другие столы, под полноэкранным) получают frame callbacks раз в секунду: 61 → 1 коммит/с у свёрнутого Chrome
- [x] Увеличение Dock при наведении — GPU-текстуры вместо бикубического масштабирования на CPU
- [x] `wp_presentation` (время vblank из ядра в DRM)
