Единый чек-лист. После каждой задачи отмечайте пункт (`[x]`) и, если нужно, дописывайте
ссылку на отчёт. Пункт считается выполненным только после проверки и без нарушения
бюджетов из [SPEC.md](SPEC.md) §2; «проверено пользователем в DRM» отмечайте отдельно.

компьютере — [DRM_CHECKLIST.md](DRM_CHECKLIST.md).

- [x] Первые CPU-кадры панелей ≤ 4 мс (Spotlight 2,52 мс, восстановление окна 1,70 мс, сворачивание 1,92 мс, меню 2,24 мс, Пункт управления 3,18 мс, Launchpad 0,69 мс)

- [x] Суммарная память композитора и помощника декодирования обоев ≤ 60 МБ (`peak_combined_anon_kib = 58552` КиБ ≈ 57,18 МиБ, декодер `5720` КиБ)

- [x] Увеличение Dock при наведении — GPU-текстуры вместо бикубического масштабирования на CPU
- [x] `wp_presentation` (время vblank из ядра в DRM)
- [x] Кадры по каждому монитору отдельно и сборка кадра к сроку перед vblank (`FEATHER_RENDER_DEADLINE=0` — по-старому)
