# Тёмная тема «Файлов» и «Заметок» — 2026-10-24

Оба клиента используют общую светлую/тёмную палитру `feather-ui::appearance::colors`:
фон, боковая панель, текст, поля, выделение, разделители, меню, листы и быстрый просмотр.
В «Заметках» сохранён жёлтый акцент; выбранная заметка в тёмном режиме имеет тёплый
приглушённый фон и светлый текст. Поля переименования не остаются белыми.

При запуске читается `~/.config/feather-de/settings.conf` (или XDG_CONFIG_HOME),
после запуска один спящий worker отслеживает каталог через inotify. Поэтому атомарная
замена файла настроек тоже доставляет смену темы. Если каталога ещё нет, отслеживается
его ближайший существующий родитель, затем watch переносится на созданный каталог.
Посторонние имена игнорируются, неизменившееся значение не вызывает перерисовку.
Чтение и ожидание происходят на worker, UI получает только готовое значение.
При закрытии клиента закрытие shutdown-сокета завершает ожидание; таймеров/опроса нет.

Проверено: 120 тестов workspace, включая создание конфигурации после начала наблюдения,
два атомарных сохранения, отсутствие лишних уведомлений и визуальные фикстуры обоих
приложений на ×1/×1,25/×2. Снимки «Файлов» (значки/список/переименование/превью) и
«Заметок» просмотрены. В настоящих клиентах проверены Light → Dark → Light → Dark:

```sh
python3 bench/client-ui-check.py files --output /tmp/feather-files-dark-check
python3 bench/client-ui-check.py notes --output /tmp/feather-notes-dark-check
```

Runner создаёт собственные данные и настройки в `/tmp`, открывает только собственный
вложенный композитор, завершает только свою группу процессов. Настройки и заметки
рабочей сессии не затрагиваются. Фикстуры — `/tmp/feather-inputs/*dark*`, снимки настоящих
клиентов — `/tmp/feather-{files,notes}-dark-check/frame.png`.

Замеры без снимка, 2880×1800, RX 580, ×1,25, с выборкой раз в секунду:

| Клиент | Простой клиента, тики/5 с | Простой композитора, тики/5 с | Пик RssAnon композитора / клиента, КиБ |
|---|---:|---:|---:|
| «Файлы» с открытым фото | 0 | 0 | 24 824 / 4 480 |
| «Заметки» | 0 | 3 | 24 976 / 1 056 |

Оба визуальных прогона отдельно дали 0/0 тиков клиента/композитора. Единичные тики
повторного прогона «Заметок» сохранены в отчёте, а не исключены. Пики памяти между
выборками и transient readback этим измерением не ограничены. SHM-буферы клиентов
не входят в RssAnon; это измерение именно приватной памяти из SPEC.
Полная приёмка прежних CPU/GL-пиков и настоящей DRM-сессии остаётся открытой.
Бюджетные прогоны: `/tmp/feather-files-dark-budget`, `/tmp/feather-notes-dark-budget`.
