# Хронология разработки Пёрышка

Новые записи добавляются сверху. Формат: дата → что сделано → почему → как проверено.

## 2026-10-24 — XWayland через xwayland-satellite, запуск по требованию (Claude)

- Композитор сам держит X-дисплей `:N` (lock-файл и оба сокета). xwayland-satellite
  стартует только при первом X-клиенте и получает сокеты через `-listenfd`. После выхода
  сокеты снова отслеживаются. Три быстрых падения подряд отключают X. При сигналах
  сокет и lock удаляются. `DISPLAY` выдаётся запускаемым программам и активации D-Bus.
- Проверено поддельным satellite. С настоящим пакетом `xwayland-satellite` проверка ещё
  предстоит. [XWAYLAND.md](docs/XWAYLAND.md).

## 2026-10-24 — простой, гашение монитора и сон (Codex)

- `ext-idle-notify` / `idle-inhibit`, один одноразовый таймер; inhibition учитывается
  только для живых видимых окон. Первое действие после гашения только будит экран.
- DRM: DPMS через очистку плоскостей, logind в отдельном потоке, hints, Lock,
  PrepareForSleep и delay-inhibitor до защищённого кадра. Вызов Suspend не мешает
  принимать сигналы; inhibitor приобретается снова после пробуждения.
- Вложенный режим не обращается к logind и не усыпляет хост. Тест с собственным
  dbus-daemon проверяет жизненный цикл inhibitor, hints и сигналы; настоящие DPMS /
  suspend/resume ещё требуют приёмки пользователя. [LOCK_POWER.md](docs/LOCK_POWER.md).

## 2026-10-24 — экран блокировки и PAM (Codex)

- Super+L и собственный экран с проверкой реального UID через PAM в worker-потоке.
  Пароль стирается, старый результат проверки не применяется при подготовке ко сну.
  Внешние блокировщики используют ext-session-lock; гибель клиента сохраняет замок.
- Отдельная защищённая сцена, перехват ввода, снятие старых захватов, ограничение
  скриншотов/clipboard. Подтверждение после показанного кадра; отклонённый lock-объект
  не может вызвать unlock даже с поведением Smithay 0.7. Возвращение из VT блокирует.
- Настоящие Wayland-клиенты во вложенном экземпляре проверяют владельца, отклонённый
  unlock, нормальный unlock, focus и fail-closed после завершения клиента. Также
  проверены Super+L, сочетания и мышь. Проверка настоящего пароля в DRM — за пользователем.
  Текущая пользовательская сессия не трогалась. [LOCK_POWER.md](docs/LOCK_POWER.md).

## 2026-10-24 — обои после обновления работающего бинарника (Codex)

- Ошибка `No such file or directory`: после пересборки Linux возвращает из
  `current_exe()` путь с ` (deleted)`. Помощник декодирования теперь запускается через
  `/proc/self/exe`, поэтому использует доступный inode работающего композитора.
- Регрессия воспроизведена на старой отдельной копии бинарника; новая версия проходит
  атомарную замену на ходу, галерею, настоящий picker и свой PNG. Реально отсутствующий
  файл по-прежнему оставляет предыдущие обои. I/O и ожидание остались на worker.
- Release без предупреждений, 111 тестов; [WALLPAPERS.md](docs/WALLPAPERS.md).
  Пики памяти помощника и прежняя приёмка GL/CPU остаются отдельными открытыми задачами.
