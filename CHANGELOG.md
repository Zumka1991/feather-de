# Хронология разработки Пёрышка

Новые записи добавляются сверху. Формат: дата → что сделано → почему → как проверено.

## 2026-10-23 — сессия с Claude (Opus 5.5)

### Графика в стиле macOS Tahoe
- **«Матовое стекло»** под Dock, меню, Control Center, Spotlight, уведомлениями и Alt+Tab:
  размытые обои 1/8 разрешения (~0,5 МБ на 4K) через pattern-шейдер tiny-skia, режим «xray»
  (показывает рабочий стол, а не окна). Ноль работы на кадр. Проверено скриншотом.
- **Скругление углов окон на GPU**: свой texture-шейдер (`src/rounded.rs`), подменяет
  стандартный только на время отрисовки окна. Нижние углы у окон с нашим заголовком, все четыре у
  квадратных CSD-приложений. Углы вычитаются из opaque-регионов (иначе чёрные уголки),
  прямой scan-out таких окон запрещён. Проверено на Konsole.
- Светлая тема по умолчанию, тёмная переключается в Control Center. Палитры, метрики macOS
  (меню-бар 24 pt, светофор 12 pt), гауссова тень окон 9-slice, шрифт Inter с кернингом.

### Прямой вывод на видеокарту (DRM/KMS)
- `src/drm_backend.rs`, `src/backend.rs`, `src/cursor.rs`, `session/start-feather-drm.sh`:
  libseat (logind) → udev → GBM/EGL → `DrmOutputManager`, кадры по vblank, libinput,
  свой курсор (xcursor, аппаратная плоскость), Ctrl+Alt+F1…F12, Ctrl+Alt+Backspace.
  Проверено пользователем на TTY3: работает.

### Оболочка
- **Dock**: запущенные приложения (по `app_id` ↔ `.desktop`/`StartupWMClass`), реальные
  иконки из темы (Papirus-Dark) в «плитках» Tahoe, перетаскивание (перестановка, закрепление,
  удаление), контекстное меню, закрепления сохраняются.
- **Launchpad** (Super+A): сетка всех приложений, поиск, страницы (колесо/свайп),
  перетаскивание в Dock, размытый фон. Плитки кэшируются, листание без растеризации,
  соседние страницы дорисовываются в простое.
- **Alt+Tab / Super+Tab**: переключатель приложений в порядке использования, панель через
  45 мс, быстрое нажатие переключает без вспышки.
- **Меню-бар**: рабочие меню приложения / «Окно» / «Справка» вместо нарисованных пунктов,
  Super+Q/W/H/M, «Оставить в Dock» в меню приложения.
- Настройки в `~/.config/feather-de/settings.conf`.

### Производительность и корректность (первая половина сессии)
- Событийный цикл calloop вместо бесконечной перерисовки: 0 % CPU в простое.
- Damage tracking, неблокирующий swap и темп по vblank хоста: Chromium с 35 до 60 FPS.
- dmabuf v4 с feedback: Mesa-клиенты больше не уходят в программный рендер.
- Ошибки ввода: фокус на невидимых окнах, принудительная рамка поверх CSD («окно в окне»),
  двойное смещение при поиске поверхности под курсором (верх и лево окон «не кликались»),
  потерянные отпускания кнопок, отсутствие `wl_pointer.leave` при перемещении окна,
  залипание Alt при уходе фокуса.
- Зомби-процессы запущенных программ теперь убираются (поток-«жнец» на каждую программу).
- Обои рисовались лишь левой верхней четвертью (`src` не задан при растягивании буфера).
- Отладочные инструменты: `FEATHER_PROFILE=1` (кадры, «клавиша → кадр»),
  `FEATHER_DEBUG_SCREENSHOT`, `FEATHER_DEBUG_OPEN`.
