# Обои Feather DE

Оригинальный набор создан 2026-10-24 встроенным инструментом image_gen для этого проекта.
Фактический размер каждого результата — 1672×941, RGB PNG; превью — 240×135.
Это новые изображения, а не файлы Apple. Оригиналы сохранены без изменения.

| Файл | Название |
|---|---|
| feather-dawn.png | Рассвет |
| feather-aurora.png | Сияние |
| feather-lake.png | Горное озеро |

Миниатюры `*-thumb.png` предназначены для галереи настроек. При применении изображение
заполняет экран с центральным кадрированием без изменения пропорций. Подготовка —
в отдельном процессе без Wayland/GL, загрузка GPU — один раз; постоянная CPU-копия
обоев не удерживается. Runtime-текстура ограничена 1920×1080 для бюджета памяти.

## Промпты генерации (built-in image_gen)

### feather-dawn

Use case: stylized-concept. Asset type: original desktop wallpaper for Feather DE. Create one refined 16:9 landscape wallpaper, ideally 3840x2160: broad translucent flowing folds suggesting an airy feather without depicting a literal feather, soft ice blue, pearl and warm peach dawn light, gentle depth and sophisticated frosted glass material, very smooth gradients. Quiet low contrast upper area for a desktop menu bar, ample calm areas around the composition. Premium understated desktop aesthetic compatible with a translucent macOS-inspired interface. Full bleed artwork only, absolutely no UI, lettering, logos, watermark, panels, borders or collage.

### feather-aurora

Use case: stylized-concept. Asset type: original desktop wallpaper for Feather DE. Create one refined 16:9 landscape wallpaper, ideally 3840x2160: sweeping luminous aurora ribbons suspended above a deep indigo and midnight blue atmosphere, restrained teal and violet highlights, smooth sculptural light and gentle depth. Calm dark upper region for a desktop menu bar, elegant uncluttered composition with negative space, soft natural luminous gradients without coarse noise. Premium original desktop artwork suitable behind a translucent macOS-inspired interface. Full bleed artwork only; no UI, text, logos, watermark, borders, stars in excessive quantity or collage.

### feather-lake

Use case: photorealistic-natural. Asset type: original desktop wallpaper for Feather DE. Create one beautiful quiet 16:9 landscape wallpaper, ideally 3840x2160: an alpine lake with glassy turquoise-blue water and layered distant mountains at first morning light, a few subtle cloud wisps, soft warm light on peaks, realistic natural photography with restrained color grading and excellent detail. Wide spacious framing, clear calm upper sky for a desktop menu bar, no central distracting foreground object. Premium peaceful desktop wallpaper, full bleed. No people, buildings, boats, signs, UI, lettering, logos, watermark, borders or collage.
