# Наставления для ИИ-агентов (ChatGPT/Codex, Claude и др.)

Проект: **Пёрышко (Feather DE)** — Wayland-композитор на Rust/Smithay 0.7 в стиле macOS Tahoe.
Цель — самое быстрое и лёгкое окружение рабочего стола. Пользователь общается по-русски.

Читать перед работой: `docs/SPEC.md` (бюджеты, архитектура, регрессии), `docs/HANDOFF.md`
(очередь задач), `CHANGELOG.md` (хронология; **после каждой задачи добавляй запись сверху**).

## Железные правила
1. **Бюджеты из `docs/SPEC.md` раздел 2 не нарушать**: 0 % CPU в простое, ≤ 1 мс работы
   композитора на кадр, ≤ 60 МБ приватной памяти. Мерить, а не предполагать
   (`FEATHER_PROFILE=1`).
2. **Цикл событий не блокировать**: никакого I/O, D-Bus, ожиданий в обработчиках.
3. **Фокус клавиатуры** — только через `refresh_focus()`, и никогда изнутри фильтра
   `KeyboardHandle::input` (дедлок): возвращай `KeyAction` и выполняй после.
4. **CPU-буферы** перерисовывать только при изменении; damage — только реальные области.
   Анимации — GPU-трансформациями.
5. Растягиваешь буфер низкого разрешения (`size` у `MemoryRenderBufferRenderElement`) —
   **всегда задавай `src`**, иначе Smithay читает за пределами текстуры.
6. `under_from_surface_tree(surface, point, location, ..)` — `point` **глобальный**,
   функция сама вычитает `location`.
7. Пользователь может работать **из сессии самого Пёрышка**. Никогда не убивай `feather-de`
   по имени (`pkill -x feather-de`): закроются все его окна. Свой тестовый экземпляр
   останавливай по PID.
8. Не отправляй нажатия/клики в чужие окна при тестах. Под Hyprland окно выбирай строго по
   PID своего процесса (`hyprctl clients -j`).

## Как проверять
- Сборка: `cargo build --release` — без ошибок и предупреждений.
- Визуально, без эмуляции ввода (кадр самого композитора, а не экрана хоста):
  `XDG_CONFIG_HOME=/tmp/fcfg FEATHER_DEBUG_OPEN=launchpad|menu-app|menu-window|cc
  FEATHER_DEBUG_SCREENSHOT=/tmp/x.png timeout 6 target/release/feather-de --windowed`.
  Если окно не видно на экране хоста (другой рабочий стол Hyprland), снимок может не
  сделаться — это ограничение вложенного режима, не ошибка.
- С клиентом: `--autostart "QT_QPA_PLATFORM=wayland konsole"`.
- Протокол клиента: `WAYLAND_DEBUG=1 <программа>`.
- FPS: `bench/anim.html` в Chromium (`--ozone-platform=wayland --enable-logging=stderr`).
- DRM-режим проверяет только пользователь (Ctrl+Alt+F3 →
  `session/start-feather-drm.sh`), лог: `~/.local/state/feather-de/drm.log`.

## Ловушки, на которых уже обжигались
- Программы с одним экземпляром (Telegram, Claude Desktop) при запуске в Пёрышке отдают
  команду уже открытому окну в другой сессии — это не ошибка композитора.
- Electron/Chromium просят client-side декорации — уважать запрос клиента, свою рамку не
  навязывать.
- При `xdg_toplevel.move/resize` обязательно `unset_grab` + `wl_pointer.leave` клиенту.
- Окно считается видимым только после первого буфера (`mapped`), фокус — только видимым.
