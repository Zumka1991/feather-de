Feather DE (Пёрышко)

A macOS-inspired Wayland desktop for Ubuntu 24.04 and newer (amd64) and Arch Linux (x86_64).

One command

One command for Ubuntu and Arch Linux. It also works on a system without a desktop (Ubuntu Server, a bare Arch): it installs Feather, the set of apps, the login screen and everything else needed. Run it as a regular user; the script asks for the sudo password itself.

curl -fsSL https://zumka1991.github.io/feather-de/install.sh | bash

As a .deb file

Download feather-de_amd64.deb and open it with a double click (or sudo apt install ./feather-de_amd64.deb). The package adds this repository by itself, like Chrome does.

Add the repository manually

sudo install -d -m 755 /etc/apt/keyrings
curl -fsSL https://zumka1991.github.io/feather-de/feather-de.asc | sudo tee /etc/apt/keyrings/feather-de.asc >/dev/null
echo 'deb [signed-by=/etc/apt/keyrings/feather-de.asc] https://zumka1991.github.io/feather-de stable main' | sudo tee /etc/apt/sources.list.d/feather-de.list
sudo apt-get update && sudo apt-get install feather-de

Key fingerprint: D5E6 C262 8719 EF1D 6068 5758 C7F9 44C1 485C 5FC4. Updates arrive with the rest of the system: sudo apt upgrade.

Arch Linux

Our own pacman repository (x86_64), signed with the same key. The command above installs Feather as one more session next to your current desktop and tells you where to pick it on the login screen; Feather only, without the set of apps: … | bash -s -- --minimal. Manual repository setup:

curl -fsSL https://zumka1991.github.io/feather-de/feather-de.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key D5E6C2628719EF1D60685758C7F944C1485C5FC4
printf '\n[feather-de]\nSigLevel = Required\nServer = https://zumka1991.github.io/feather-de/arch/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu feather-de

From then on, updates are sudo pacman -Syu. To start: log out and pick “Feather (direct DRM/KMS output)” on the login screen.
