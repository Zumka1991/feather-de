Пёрышко (Feather DE)

Рабочий стол Wayland в стиле macOS для Ubuntu 24.04 и новее (amd64).

Одной командой

Подходит и для Ubuntu Server без рабочего стола: ставит Пёрышко, его экран входа и всё нужное. Запускайте обычным пользователем, пароль sudo скрипт спросит сам.

curl -fsSL https://zumka1991.github.io/feather-de/install.sh | bash

Файлом .deb

Скачать feather-de_amd64.deb и открыть двойным щелчком (или sudo apt install ./feather-de_amd64.deb). Пакет сам подключит этот репозиторий, как Chrome.

Репозиторий вручную

sudo install -d -m 755 /etc/apt/keyrings
curl -fsSL https://zumka1991.github.io/feather-de/feather-de.asc | sudo tee /etc/apt/keyrings/feather-de.asc >/dev/null
echo 'deb [signed-by=/etc/apt/keyrings/feather-de.asc] https://zumka1991.github.io/feather-de stable main' | sudo tee /etc/apt/sources.list.d/feather-de.list
sudo apt-get update && sudo apt-get install feather-de

Отпечаток ключа: D5E6 C262 8719 EF1D 6068 5758 C7F9 44C1 485C 5FC4. Обновления приходят вместе с системой: sudo apt upgrade. Исходный код: github.com/Zumka1991/feather-de.
